# Masters Compendium

Помощник мастера для настольных игр **D&D 5e (2014)**: программа на ПК мастера + веб-клиент, в который игроки заходят с телефонов по QR-коду. Работает в локальной сети (Wi-Fi) или через интернет (tuna.am / Cloudflare).

*A Game Master companion for **D&D 5e (2014)**: a Windows desktop app for the GM plus a web client players open on their phones via QR code. Works on a local network or over the internet.*

## Что умеет

- **Листы персонажей** — пошаговое создание, всё считается само: модификаторы, навыки, КД, атаки, ячейки заклинаний (319 заклинаний SRD), уровни и опыт; отдельный файл-«создатель персонажа» для игроков без интернета.
- **Интерактивная карта** — фишки, туман войны (скрывает и противников), сетка квадратная или шестиугольная, шаблоны заклинаний, трудная местность, пометки для всех, генератор случайных карт (лес, пещера, подземелье, город, рынок, таверна, канализация, деревня, болото, пустыня, зима…).
- **Бой по правилам** — инициатива, атаки с броском и уроном, спасброски по площади, атаки по возможности, захват, укрытие, внезапность, спасброски от смерти, повторяющиеся эффекты (яд и т.п.), решения мастера с откатом, журнал действий игроков.
- **Мир** — календарь, время, случайная погода с эффектами на карте, таймеры, тайные броски, припасы, журнал сессий.
- **Партия** — общий склад, лавка (продажа с одобрения мастера), раздатки, заметки, бестиарий (импорт с ttg.club).
- **Звук** — атмосфера из настоящих записей, эффекты, свои звуки и музыка; можно транслировать игрокам.
- **3D-кубики** с эффектами (огонь, лёд, природа, вода, космос…), привал у костра, «комната ожидания» с мини-играми.
- Интерфейс на русском и английском.

## Запуск (Windows 10/11)

Нужен Python 3.11+.

```
run.bat         — запуск из исходников (сам поставит PyQt6, aiohttp, qrcode)
debug_run.bat   — то же с консолью для текста ошибок
build.bat       — собрать портативный dist\MastersCompendium.exe
```

При первом запуске разрешите доступ в брандмауэре Windows — иначе телефоны не подключатся.

## Устройство

- `main.py`, `mc/ui/` — окно мастера (PyQt6): лобби, QR-код, туннели.
- `mc/server*.py` — сервер на aiohttp (WebSocket): кампания, бой, карта, мир, звук.
- `web/` — клиент на чистом JavaScript (без сборки): лист, карта, бой, кубики.
- `tools/` — сборка справочника SRD и иконок.
